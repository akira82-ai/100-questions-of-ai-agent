# Answer Guide (v2)

This is the English edition of *100 Questions of DeepSeek Harness*. It follows the Chinese source version and keeps its practical, judgment-first style.

Each answer starts with a direct conclusion, then gives the mechanism, a concrete action, and source links where they matter. Commands and product behavior are pinned to DeepSeek Harness `0.1.0-rc.6` and the surrounding material available on 2026-08-17 unless a question says otherwise. DeepSeek Harness is still in developer preview, so check the current official documentation before running a command.

The book covers Q1-Q100 in seven chapters:

| File | Coverage |
|---|---|
| `01-the-hidden-battlefield-beyond-the-model.md` | Foundations and positioning, Q1-Q14 |
| `02-get-it-running-in-three-commands.md` | First run and setup, Q15-Q28 |
| `03-open-the-case-and-find-plugins.md` | Architecture and plugins, Q29-Q42 |
| `04-logs-and-money-in-practice.md` | Debugging, cost, and source literacy, Q43-Q58 |
| `05-real-scenarios-and-reusable-wheels.md` | Practical scenarios, Q59-Q72 |
| `06-engineering-for-production.md` | Production engineering, Q73-Q86 |
| `07-judgment-that-outlasts-tools.md` | Durable judgment, Q87-Q100 |

The English edition translates the reader-facing content. Source filenames and links that point to Chinese documentation remain Chinese where that preserves traceability.
