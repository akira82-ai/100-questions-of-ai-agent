# Answer Guide (v1)

This is the English edition of *100 Questions about Agent Skills*. It follows the Chinese source version and keeps its practical, judgment-first style.

Each answer starts with a direct conclusion, then gives the mechanism, a concrete action, and source links where they matter. Facts and numbers are pinned to what was verifiable on 2026-08-31: star counts and marketplace stats are snapshots of that date, Claude Code behavior is checked against the v2.1.251-era build, Codex against v0.146-v0.150, and Gemini CLI against v0.39-v0.44. Hosts iterate fast, so re-check the current official documentation before running anything.

The book covers Q1-Q100 in six chapters:

| File | Coverage |
|---|---|
| `01-how-a-single-folder-gets-smart.md` | How skills actually work, Q1-Q18 |
| `02-why-installed-skills-dont-work.md` | Troubleshooting, performance, and drift, Q19-Q32 |
| `03-write-your-craft-into-a-skill.md` | Skill authoring and evaluation, Q33-Q52 |
| `04-do-skills-survive-a-host-swap.md` | The spec, hosts, and distribution, Q53-Q68 |
| `05-four-in-ten-skills-ship-with-holes.md` | Security, supply chain, and governance, Q69-Q86 |
| `06-where-skills-go-next.md` | Evolution, API skills, and what lasts, Q87-Q100 |

The English edition translates the reader-facing content. Source links stay as published; a few community references point to Chinese-language pages where those were the primary sources.
