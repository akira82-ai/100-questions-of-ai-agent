## Notes on Using the Sources

The main text of this book strictly follows these principles:

- **No citations in the main text.** All arguments, data, frameworks, and quotable lines are written as "what the author wants to say," without exposing the source or the analysis process.
- **Source attribution is consolidated in this appendix.** If a reader wants to trace any piece of information, start here.
- **The three categories are divided by source attribute:** official regulation and vendor documentation (authoritative), overseas deep sources (first-hand depth), domestic community and industry (local practice). Within each category, sub-groups by theme make targeted tracing easy.
- **The source structure is mixed.** Official docs, official blogs, community discussions, experience posts, case analyses, and academic papers are all covered, avoiding any single source dominating the book.

This appendix is not a "reference list"; it is a knowledge map. It tells the reader which domains, which people, and which practices this book's knowledge comes from.

The value of knowledge lies in its flow. The authors of the raw sources shared this knowledge openly, a contribution to the whole industry. What this book does is weave that scattered knowledge into a more coherent net.
