# Answer Guide (v1)

This is the English edition of *100 Questions of Prompt Engineering*. It follows the Chinese source version and keeps its practical, judgment-first style.

Each answer opens with a direct conclusion, then gives the mechanism, a concrete action, and source links where they matter. Model behavior, guide citations, and product facts are pinned to the sources archived on 2026-08-24/25 unless a question says otherwise. Vendor guidance moves fast - check the current official documentation before relying on any model-specific behavior.

The book covers Q1-Q100 in five chapters:

| File | Coverage |
|---|---|
| `01-is-prompt-engineering-still-worth-learning.md` | Positioning, myths, and the minimum to learn, Q1-Q12 |
| `02-from-one-liner-to-structure.md` | Structured prompts: skeleton, order, examples, templates, Q13-Q34 |
| `03-why-copied-prompts-fail.md` | Failure modes and debugging, Q35-Q58 |
| `04-playbooks-for-daily-work.md` | Copy-and-use scenarios: reports, minutes, email, decks, data, Q59-Q84 |
| `05-beyond-templates-what-comes-next.md` | Method, evaluation, and what comes after prompts, Q85-Q100 |

The English edition translates the reader-facing content. Source filenames and links that point to Chinese documentation remain Chinese where that preserves traceability.

Style notes: conversational second person, short sentences, direct-answer openers without bold formatting, no teaser sentences, no source narration inside the body text. Templates appear as copy-ready code blocks; image captions carry the source URL and snapshot date. Cross-references use the Q-number form ("see Q57").
